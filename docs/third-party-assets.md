# 品牌资源来源

`web/src/assets/verymath-logo.png` 原样取自 [VeryMath-textbook-copilot 的 public/brand-icon.png](https://github.com/VeryMath/VeryMath-textbook-copilot/blob/main/public/brand-icon.png)，用于工作台左上角的 VeryMath 品牌标识。

来源仓库的许可证一并保留在 `web/src/assets/VeryMath-LICENSE.txt`。图像内容和配色未修改，仅通过 CSS 调整显示尺寸；Co-Math 产品名称继续显示在标识下方。

`web/public/pdf-assets/cmaps/` 和 `web/public/pdf-assets/standard_fonts/` 来自已安装的 `pdfjs-dist` 6.3.289，供本地 PDF 阅读器显示中文字符与标准字体。各目录附带的原许可证一并保留。
